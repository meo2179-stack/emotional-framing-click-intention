# Emotional Framing and Decision-Making: A Simulated Data Analysis of How Message Tone Influences Click Intention

## Project Overview
This project presents the design of a simulated psychology data analysis exploring how emotional framing in digital headlines may influence users’ click intention. The project combines concepts from psychology, behavioral science, and digital media to examine how emotionally framed language can affect decision-making and engagement behavior.

Rather than conducting a real experiment, this project outlines the structure of a hypothetical study, including the experimental design, proposed code structure, data collection process, and planned statistical analyses.

## Research Question
How does emotional framing in digital headlines influence users’ likelihood of clicking on content?

## Hypothesis
Emotionally framed headlines, particularly those using curiosity, urgency, or validation-based language, will produce higher click intention scores than neutral headlines.

## Planned Methods
Participants would view a series of headlines categorized into different emotional framing conditions:
- Neutral
- Fear/Urgency
- Hopeful
- Curiosity-Driven
- Validation/Reassurance

Participants would rate how likely they would be to click each headline using a 1–10 scale.

The resulting data would then be analyzed using statistical methods such as descriptive statistics, ANOVA, and data visualization techniques.
